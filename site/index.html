macOS · Hyperliquid · Rust

A native macOS desktop for one Hyperliquid account.

Portfolio, markets, funding and history, with orders and positions you can manage from the same window.

Get started Source on GitHub
$ git clone https://github.com/sercanatalik/galata-desk
$ cd galata-desk
$ cargo run -p galata-desk
You need macOS and Rust.

Markets in fullscreen: a workspace you arrange, linked by channel. The account shown is one of Hyperliquid's own public vaults.

Status: 0.x, macOS only. It runs from source, built with Cargo as above.

What it takes to trade

You connect by signing a message in your browser wallet. Nothing is signed for trading unless you save an API key and confirm an action.

Before anything is sent

  • Trading needs an API wallet key, saved in Settings and kept in the macOS Keychain.
  • Nothing is sent until you confirm.
  • Mainnet trading also needs Allow trading on mainnet, off by default.
  • Every action passes one gate in the core (trade::gate) that checks the network, the key and that the key is an approved API wallet of the account.

It never

  • asks for a seed phrase or a private key to connect;
  • retries an order on its own;
  • writes a key or seed phrase to its storage;
  • closes a position other than reduce-only.

The connect page, served by the app to your browser. Signing in is not a transaction and grants no permission to trade.
